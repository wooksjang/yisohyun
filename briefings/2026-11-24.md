## 2. 🌤️ 날씨 (서울 기준)

| 구분 | 내용 |
|---|---|
| 하늘 | 오전·오후 모두 **맑음** ☀️ |
| 기온 | 아침 **-2 ~ -1℃** → 낮 **3℃** (낮에도 한겨울처럼 추워요) |
| 바람 | 찬 대륙고기압 영향으로 **바람이 강해요** → 체감온도는 영하 5℃ 안팎 |
| 강수 | 강수확률 10% → **우산은 필요 없어요** ☂️❌ |
| 노면 | 출근길 **도로 살얼음·빙판 주의** |

```
기온 흐름   06시 ▁   09시 ▁▂   12시 ▃▄   15시 ▄▅   18시 ▃   21시 ▂
           -2℃     -1℃       2℃        3℃       1℃     -1℃   (대략)
           └──── 체감은 표시보다 3~4℃ 더 낮아요 ────┘
```

👕 **옷차림**: 히트텍 같은 발열 내의 + 니트 + **패딩(롱패딩 추천)**, 목도리·장갑까지 챙기세요. 지난 브리핑(11/11, 낮 16℃) 때보다 **13℃ 넘게** 떨어졌으니 겨울옷으로 바꿔 입을 때예요.

## 6. 📚 학업

⚠️ **설정된 학업 계획을 아직 찾지 못했어요.**
